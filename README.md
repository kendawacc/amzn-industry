#Industry

Industry is a fully integrated platform that acts as the core software layer for modern warehouse operations. Rather than relying on fragmented tools, it unifies inventory, labor, transportation, automation, analytics, and safety systems into a single cohesive environment.

## Labor Assignment

### Page 13

![Page 13](README/page-13.png)

Labor Assignment 01
A system that automatically assigns associates to
tasks based on data-driven insights.
• Only associates who are trained in a given path are eligible
for assignment. Untrained associates will not be considered
under any circumstances!
• If an associate prefers a specific path, they will be among
the first selected for it, with all other parameters ignored—
unless there is high demand in another area that requires their
assignment.
• Associates with higher hours in a particular path will have a
reduced chance of being assigned to it, and will instead be
directed toward paths where they have less experience,
unless efficiency requirements demand otherwise.

Labor Assignment 04
Manager Request : If necessary, a manager may
request additional team members from another
manager when their own team does not have
enough staff to complete a units.
• The request must be approved by a requested manager
before it becomes effective.
• If the requested manager’s team has surplus capacity, or if
a task is of the highest priority, normal conditions are
overridden. The requested manager will be instructed to
reassign team members to that task, and an operations
manager will be notified if staffing requirements are not met.

## Associate

![Page 17](README/page-17.png)

Associate 01
Associate Insight
• Provides valuable data to support associate growth and
streamline decision-making by highlighting key
information:
• Preferred Path – Identify which tasks or paths an associate
enjoys, enabling quicker and more efficient labor
assignments.
• Learned Skills – View the skills an associate has mastered
within different paths (stow, pick, etc.).
• Desired Skills – Track the skills an associate is interested in
learning, helping guide faster development and career
progression.

### Page 18

Data Metrics
A graph-based tool to visualize associate labor
data.

## TDR

![Page 20](README/page-20.png)

TDR 01
Provides a live 3D view of TDR dock doors, showing which
doors are open, closed, or connected to trailers. Users can
navigate the 3D space with touch controls, or use quick-
action options for fast docking and releasing. If a door is being
operated, a floating image of the associate’s profile picture
will appear near the door, along with text above the 3D dock
door that displays its location.
• Live 3D view of TDR dock doors with real-time status (open,
closed, or trailer-docked)
• Touch controls let users move freely around the 3D space
• Quick-action options for fast docking and releasing
• Floating profile images appear when an associate is
operating a door
• Dock door location text is displayed above each 3D door
for easy identification

## Yard

![Page 44](README/page-44.png)

Yard 01
The system provides a live 3D view of all trailers currently in the
yard, allowing managers and associates to monitor real-time
trailer positions. Users can easily filter or select trailers by
department, load time, or other key details to quickly identify
priority loads. This ensures greater visibility, faster decision-
making, and more efficient yard management.
• Live 3D view of all trailers currently in the yard
• Real-time positioning and status updates for each trailer
• Ability to filter and select trailers by department
• Option to filter by load time to prioritize urgent loads
• Provides clear visibility for managers and associates to
track yard activity
• Supports faster decision-making and more efficient trailer
management
